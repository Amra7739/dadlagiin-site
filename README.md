# Дадлага.mn (Dadlaga.mn) - Монголын Дадлагын Бүрэн Ажиллагаатай Full-Stack Платформ

Монголын их, дээд сургуулийн оюутнууд болон тэргүүлэгч ажил олгогчдыг холбосон **Full-Stack веб платформ**. Node.js, өндөр хурдны SQLite өгөгдлийн сан, Компаниудад зориулсан ATS (Applicant Tracking System), Оюутны портал болон бүрэн REST API-тай.

---

## 🌟 Гол боломж, онцлогууд (Full-Stack Features)

### 1. Сервер & Өгөгдлийн сан (Backend & SQLite Database):
- **Node.js Native SQLite Database (`dadlaga.db`):** 
  - Төслийн үндсэн фолдерт шууд `dadlaga.db` файл байршиж бүх мэдээллийг хадгална.
  - `users` (Хэрэглэгчийн бүртгэл, нууц үгийн крипто хамгаалалт)
  - `internships` (56 бодит жишээ дадлагын зар, 14 мэргэжлийн чиглэл)
  - `applications` (Оюутнуудын ирүүлсэн анкет, CV, хяналтын төлөвүүд)
- **REST API Эндпойнтууд:**
  - `POST /api/auth/register` — Шинэ оюутан/компани бүртгэх
  - `POST /api/auth/login` — Системд нэвтрэх
  - `POST /api/auth/demo` — 1-Товшилтоор Оюутан эсвэл Компаниар нэвтрэх
  - `GET /api/internships` — Бүх зарыг хайлт, шүүлтүүрээр татах
  - `POST /api/internships` — Ажил олгогч шинэ дадлагын зар нийтлэх
  - `GET /api/applications` — Анкетуудыг ATS хүснэгтээр татах
  - `POST /api/applications` — Оюутан анкет, CV илгээх
  - `PATCH /api/applications/:id/status` — Анкетын төлөв солих (`reviewing`, `interview`, `accepted`, `rejected`)
  - `GET /api/stats` — Нэгдсэн статистик тоолуур

### 2. Бүртгэл & Нэвтрэх систем (Real Production Auth & Profile):
- **Тусдаа зориулалтын хуудсууд:**
  - `login.html` — Оюутан/Байгууллагын нэвтрэх хуудас, нууц үг харах/нуух товч, "Намайг санах", "Нууц үгээ мартсан уу?" сэргээх систем, 1-Click Demo.
  - `register.html` — Оюутан ба Компанийн ялгаатай талбаруудтай (Сургууль, Мэргэжил, Курс / Компани, Салбар, Вэбсайт), нууц үгийн хүч хэмжигч (Password Strength Meter).
- **Хэрэглэгчийн цэс (Navbar User Dropdown):**
  - Нэвтэрсэн үед хэрэглэгчийн нэр, төрөл (🎓 Оюутан / 🏢 Компани), аватар дүрс харагдаж, дарахад ATS самбар, Профайл засах, Зарууд, Гарах цэс гарч ирнэ.
- **Шуурхай Модал (Auth Modal):**
  - Бүх хуудаснаас хуудсаа солихгүйгээр шууд нэвтрэх/бүртгүүлэх шилэн цонх.
- **⚡ 1-Click Demo Login:**
  - 🎓 **Оюутнаар турших:** Батболд Тэмүүлэн (`student@dadlaga.mn` / `demo123`)
  - 🏢 **Компаниар турших:** Голомт Банк Хүний Нөөц (`hr@golomtbank.com` / `demo123`)

### 3. Хяналтын нэгдсэн самбар (`dashboard.html`):
- **Компанийн ATS горим:** Ирсэн бүх анкетуудыг хүснэгтээр харах, CV татаж үзэх, төлөвийг (Шалгаж буй / Ярилцлага / Тэнцсэн / Татгалзсан) шууд солих.
- **Оюутны портал горим:** Илгээсэн өргөдлүүдийнхээ хариу статус, хадгалсан заруудыг хянах.
- Дээрх 2 горимын хооронд шууд товшиж шилжих унтраалгатай.

### 4. Дизайн & Хэрэглэгчийн туршлага (UI/UX):
- Хөдөлгөөнт арын дэвсгэр (Animated Ambient Mesh Orbs & Matrix Grid).
- Dark / Light Mode (Өдөр/Шөнийн горим солигч).
- 3D Card Hover Tilt эффект.
- Live Form Preview (Зар бичих үед бодит харагдац нь шууд өөрчлөгдөнө).
- Интерактив CV бэлэн байдлын тооцоолуур (`tips.html`).

## 💻 Хэрхэн ажиллуулах вэ? (Quick Start)

### 1. Серверийг асаах:
```bash
node server.js
```

### 2. Хөтөч дээрээ нээх:
```text
http://localhost:3000
```

*(Мөн серверийг асаахгүй үед ч `index.html` файлыг шууд хөтчөөрөө нээн ашиглах боломжтой бөгөөд LocalStorage-оор өгөгдлөө автоматаар зохицуулна)*
